CentralPoint installieren

Letzte Änderung 29.08.2026 · Version 1 · Seiten-ID 722

Entwurf – diese Seite ist noch nicht geprüft und kann Fehler enthalten.

Der CentralPoint ist der zentrale Server der Installation: Er verwaltet Stammdaten, Kassendaten, Lizenzen und Berichte und verteilt Änderungen an die Filialen.

Voraussetzungen

  • Server nach ITR Partner Service → Betrieb & Administration → Systemvoraussetzungen.
  • Eine eingerichtete Datenbank mit Schema und Benutzer — siehe ITR Partner Service → Produkte → Datenbank für den CentralPoint einrichten.
  • Lizenz aus dem Partner-Portal.

So gehen Sie vor

  1. Installationspaket aus dem Partner-Portal laden. Es heißt Setup-itrCP<Version>_….exe.
  2. Setup ausführen. Standardverzeichnis ist C:\GoodCompany\itrCP\.
  3. Datenbank verbinden und initialisieren — siehe unten.
  4. Anwendung registrieren und die Lizenz aktivieren, siehe ITR Partner Service → Produkte → Lizenz aktivieren.

Datenbank verbinden

Menüweg: Programm → Einstellungen

Feld Inhalt
URL jdbc:mysql://<Rechner>:<Port>/<Schema>, zum Beispiel jdbc:mysql://localhost:3306/goodcompany. Liegt die Datenbank auf einem anderen Rechner, dessen IP statt localhost eintragen. Standardport ist 3306.
UserName der bei der Datenbankeinrichtung angelegte Benutzer, üblich goodcompany
Passwort dessen Kennwort

Das Kennwort muss nach der Eingabe über die Schaltfläche Passwort verschlüsseln gesichert werden. Ohne die verschlüsselte Form kommt trotz sonst richtiger Angaben keine Verbindung zustande.

Datenbank initialisieren

Über Datenbank initialisieren — nach Eingabe eines Kennworts — öffnet sich der Dialog mit diesen Schritten:

  1. Datenbankverbindung konfigurieren — die Angaben von oben eintragen.
  2. Datenbankverbindung testen — bei richtigen Angaben bestätigt der CentralPoint die Verbindung.
  3. Datenbanktabellen anlegen — legt die Tabellen im Schema an.
  4. Initialdaten importieren — übernimmt Standarddaten wie Orte, Postleitzahlen und Vorwahlen.
  5. Verlassen — beendet die Initialisierung.

[SCREENSHOT: Dialog Datenbank initialisieren mit den fünf Schaltflächen]

Ergebnis prüfen

  • Der Verbindungstest ist erfolgreich.
  • Das Schema enthält die Tabellen.
  • Der CentralPoint startet ohne Fehlermeldung und zeigt die lizenzierten Module.

Zweck Pfad
Konfiguration der Protokollierung %ProgramData%\it relations GmbH\ITRCP\logging.xml
Standardprotokoll C:\GoodCompany\itrCP\log\itrcp_0_0.log
Protokoll im Benutzerkontext C:\Users\<Benutzer>\.itrelations\ITRCP\itrcp_0_0.log

Terminalserver und mehrere Benutzer

Für den Betrieb des CentralPoint auf einem Terminalserver oder in einer Mehrbenutzerumgebung besteht keine Gewährleistung. Die Verantwortung liegt beim Systemadministrator.

Bei einem Update von einer Version vor 5.36 ist zu beachten: Das Konfigurationsverzeichnis wandert von %appdata%\it relations GmbH\itrcp\xml nach %programdata%\it relations GmbH\itrcp\xml. Beim ersten Start verschiebt der CentralPoint das alte Verzeichnis samt Berechtigungen — das gelingt nur für den ersten Benutzer, alle weiteren haben danach keine Rechte.

Abhilfe:

  1. Das alte Verzeichnis unter %appdata% für jeden Benutzer löschen.
  2. Das neue Verzeichnis unter %programdata% für alle Benutzer freigeben.
  3. Sicherstellen, dass alle Benutzer die nötigen RDP-Berechtigungen haben.
@echo off
rd /s /q "%appdata%\it relations GmbH\itrcp"
icacls "%programdata%\it relations GmbH\itrcp" /grant *S-1-1-0:(R)

Ausnahme bei mehreren Datenbankschemata: Dort muss der Anwender die Datei ändern dürfen, weil die gewählte Datenbank in die connection.xml geschrieben wird. Sonst lädt der CentralPoint trotz Auswahl immer dasselbe Schema. In dem Fall statt (R) die Berechtigung (M) vergeben.
