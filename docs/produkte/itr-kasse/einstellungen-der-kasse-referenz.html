Einstellungen der Kasse: Referenz

Letzte Änderung 29.08.2026 · Version 1 · Seiten-ID 775

Entwurf – diese Seite ist noch nicht geprüft und kann Fehler enthalten.

Die ITR Kasse wird über eine Parameterliste konfiguriert, die nach Bereichen gegliedert ist. Diese Seite beschreibt den Umgang mit der Liste und führt die dokumentierten Parameter je Bereich auf.

Die Parameterliste bedienen

Die Parameterliste liegt unter Admin-Seiten → Einstellungen → Admin → Alle Einstellungen. Der Kopf der Seite zeigt eine Übersicht über den eingesteckten Dongle und die freigeschalteten Module.

Element Zweck
Import Übernimmt alle Parameter einer anderen Kasse aus einer Datei
Export Schreibt alle Parameter dieser Kasse in eine Datei, die an einer anderen Kasse importiert werden kann
Bearbeitung starten Gibt die Parameter zur Änderung frei. Ohne diesen Schritt ist die Liste schreibgeschützt
Such- und Sortierfeld Filtert die Liste nach Namen oder Namensteilen. Die Eingabe Maske zeigt alle Parameter, deren Name das Wort enthält
Parameter Die Liste selbst, gefiltert nach dem Suchfeld
Beschreibung der Parameter Erklärungstext zum gewählten Parameter. Die Beschreibungen werden mit jeder Version ergänzt

[SCREENSHOT: ITR Kasse, Admin-Seiten → Einstellungen → Admin → Alle Einstellungen, gesamte Seite]

Ein Import überschreibt die Parameter dieser Kasse vollständig mit denen der Quellkasse. Exportieren Sie vorher den bestehenden Stand, damit Sie zurückkehren können.

Waage

Für Waagen gibt es einen Parameter, der den Wiegevorgang automatisch bestätigt. Das ist etwa dort sinnvoll, wo sich das Gewicht nach dem Auflegen nicht mehr verändert. Der Parameter wird an der Kasse in der Datei cr.properties ergänzt:

Properties
Misc.ScaleRader.AutoOkay=true

Bereiche ohne dokumentierte Parameter

Die folgenden Bereiche existieren in der Parameterliste, die Quelle führt zu ihnen jedoch keine Parameter auf: BarCode-Druck zur Bon-Suche, BarCode-Scanner, Bezahlterminal, Bon, Bon-Warteschlange, Bonsummen-BarCode Druck, Bonuspunkte, Button, CoinMaster, Dallas-Schlüssel, Dialog, Eingabe, EnableCondition, Entries, Farben, Flughafen, Frame, Glory, Hardware, Kasse, Kundenportal, Lager, LinkedGroup, Login, Modifier, Operator, Panels, PrePaid, Price, RotationSupport, Secucard, Serielle Schubladen, SmartSchank, SmartTill, Stampay, Steuer, Storno, Update, UseFactor, VideoServer.
