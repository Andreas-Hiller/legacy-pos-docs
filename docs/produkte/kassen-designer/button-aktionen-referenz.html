Button-Aktionen: Referenz

Entwurf – diese Seite ist noch nicht geprüft und kann Fehler enthalten.

Letzte Änderung 29.08.2026 · Version 1 · Seiten-ID 774

Jeder Button der ITR Kasse trägt genau eine Aktion. Diese Seite fasst die verfügbaren Aktionen nach Aufgabenbereich zusammen und nennt je Aktion die wichtigsten Parameter.

Aufbau

Im Button Designer wird die Aktion eines Buttons über mehrere Reiter festgelegt. Neben der Voreinstellung Keine Aktion stehen zur Verfügung:

Reiter Zweck
Aktion Kommandos der Kasse, siehe die Abschnitte unten
Artikel/Artikel-Gruppe Belegt den Button mit Artikeln, Warengruppen, Hauptgruppen oder Auswahlfenstern
Modifier Weist dem Button einen Preis-, Rabatt- oder Steuer-Modifier zu
Maskenwechsel Wechselt auf eine andere Maske
Berichte Ruft einen Bericht an der Kasse auf oder druckt ihn
Bildschirmtastatur Legt Tasten für ein Bildschirmtastatur-Panel an
Makro Führt mehrere Kommandos hintereinander aus
Kommentar Freitext zur Dokumentation des Buttons, wird auch als Tooltip im Panel Designer angezeigt

Der Umfang der Aktionen wächst mit den Kassenversionen. Weicht die Auswahl im Designer von dieser Seite ab, prüfen Sie die Version der Kasse.

Makros

Über den Reiter Makro werden mehrere Kommandos zu einer Schaltfläche zusammengefasst. Zwei Beispiele aus der Praxis:

Auszahlung — nach Eingabe des Betrags über den Ziffernblock:

  1. Kommando Tastaturpuffer: mal macht den eingegebenen Wert zur Menge des folgenden Artikels.
  2. Ein Hilfsartikel mit dem Preis 1,00, der Eigenschaft „überschreibbar“ und ohne hinterlegten Steuersatz wird gebucht.
  3. Die Artikelmenge wird negativ gesetzt.
  4. Es wird auf einen Bontyp gewechselt, der Umsatz und Warenbestand nicht verändert, das Kassen-Ist aber verringert.
  5. Bezahlen direkt bestätigen schließt den Bon ohne weitere Eingaben ab.

Im Haus — alle folgenden Artikel auf Preisgruppe 2 und Steuer 2, Bon auf Bontyp 7:

  1. Tabellenfokus aufheben, damit kein Artikel markiert ist und die Umstellung erst für den nächsten Artikel gilt.
  2. Shift auf Preisgruppe 2.
  3. Shift auf Steuer 2.
  4. Wechsel auf den gewünschten Bontyp, was die spätere Auswertung der Im-Haus-Verkäufe erlaubt.
